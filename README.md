# GatorTools.github.io

Le site de l'organisation GatorTools : présentation des logiciels et liens de
téléchargement. Pages statiques, sans outil de construction : GitHub Pages
publie la branche `main` telle quelle.

- `index.html` : accueil de l'organisation
- `clonegator/` : présentation, détails et téléchargement de CloneGator ;
  `versions.js` lit les releases de `GatorTools/CloneGator` au chargement
- `img/` : logos, réduits à partir des originaux
